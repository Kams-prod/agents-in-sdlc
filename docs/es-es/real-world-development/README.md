Explora GitHub Copilot a lo largo del ciclo de vida del desarrollo de software mediante situaciones realistas, una aplicación completa y un backlog compartido. Trabajarás de forma iterativa para planificar cambios, crear código, probar el comportamiento, revisar solicitudes de incorporación de cambios y gestionar el trabajo con agentes.

## Escenario

Te acabas de incorporar como desarrollador al equipo de Tailspin Toys, una empresa ficticia que ofrece financiación colectiva para juegos de mesa con temática de desarrollo. El backlog del equipo ya está registrado como incidencias de GitHub, listas para que elijas por cuál empezar. Incluye tareas de funcionalidad, como el filtrado y la paginación, y mejoras de calidad, como la accesibilidad y los estándares de programación.

## Elige tu entorno

GitHub Copilot te acompaña en el entorno donde trabajes. Elige el que mejor se adapte a tu forma de desarrollar. Cada taller empieza con su propia configuración y utiliza el escenario compartido de Tailspin Toys.

### [GitHub Copilot CLI][cli]

Usa el asistente con agentes en el terminal. Trabaja con los modos Plan y Autopilot, instrucciones, habilidades, agentes personalizados, Playwright MCP, Agent Merge y comandos de barra prácticos.

### [Aplicación GitHub Copilot][app]

Ejecuta sesiones de agente en paralelo, cambia los modos de sesión, colabora en lienzos y gestiona incidencias y solicitudes de incorporación de cambios de GitHub desde la aplicación de escritorio.

### [Agente de GitHub Copilot en la nube][cloud]

Asigna incidencias de GitHub a un agente asíncrono, guía su trabajo, supervisa el progreso y revisa las solicitudes de incorporación de cambios que abre.

### [Visual Studio Code][vscode]

Usa GitHub Copilot en Visual Studio Code y GitHub Codespaces. Trabaja con el modo agente de Copilot Chat, servidores MCP y agentes personalizados sin salir del editor.
