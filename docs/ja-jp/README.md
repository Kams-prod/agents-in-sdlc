学びたい内容と、どこまで深く学びたいかに合わせてワークショップを選びます。**はじめの一歩**では GitHub Copilot をガイドに沿って体験します。**実践的な開発**では、完成したアプリケーションとチームのバックログを使って、本番を想定したワークフローを実践します。

## はじめの一歩

既存のアプリケーションや詳細な開発シナリオを用意せずに、GitHub Copilot を体験できるガイド付きの入門ワークショップです。どのワークショップも小さく始め、製品を使いながら学び、ひととおりのワークフローを体験します。

すべてのワークショップで、空のフォルダーから同じ Space Quiz を作ります。学びたいツールを選ぶことも、複数のワークショップを完了して、それぞれの使い方を比較することもできます。

### [GitHub Copilot app ツアー][first-steps-app]

空のフォルダーからカラフルな Space Quiz を作り、作成、改善、テスト、プロジェクトの指示の記録、公開、作業の計画、Issue の実装、プルリクエストのレビューとマージ、定期的な作業の自動化を行い、Canvas 拡張機能も体験します。

### [GitHub Copilot CLI のはじめの一歩][first-steps-cli]

ターミナル中心の開発の流れを学びます。Git に変更を記録する前にアプリを作成して差分をレビューし、worktree で複数のセッションを並行して実行し、編集前に計画を立て、コンテキストを管理します。その後、シェルを離れずにプルリクエストを作成、マージし、作業を委任します。

### [Visual Studio Code のはじめの一歩][first-steps-vscode]

エディター中心の開発の流れを体験します。ワークスペースでアプリを作成し、統合ブラウザーで要素を調整し、コンテキストを確認して、Git に変更を記録する前にテストします。編集前に計画を立て、VS Code を離れずに GitHub ツールで Issue、プルリクエスト、クラウドセッションを扱います。

## 実践的な開発

現実的なシナリオ、完成したアプリケーション、共有バックログを使って、ソフトウェア開発ライフサイクル全体で GitHub Copilot を体験します。反復的に変更を計画してコードを作成し、動作をテストし、プルリクエストをレビューし、エージェントを使って作業を管理します。

### [実践的な開発ワークショップを見る][real-world-development]

GitHub Copilot CLI、GitHub Copilot app、GitHub Copilot cloud agent、Visual Studio Code から選びます。

> [!CAUTION]
> GitHub Copilot は決定論的ではなく確率的に動作するため、生成されるコードや変更されるファイルは例と異なる場合があります。多少の違いは想定される動作です。
>
> 講師が進行するワークショップで正しく動作しない場合は、メンターに相談してください。
