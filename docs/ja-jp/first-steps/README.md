「はじめの一歩」のワークショップは、既存のアプリケーションや詳細な開発シナリオを用意せずに GitHub Copilot を体験できる、ガイド付きの入門コースです。どのワークショップも小さく始め、製品を使いながら学び、ひととおりのワークフローを体験します。

すべてのワークショップで、空のフォルダーから同じ Space Quiz を作ります。学びたいツールを選ぶことも、複数のワークショップを完了して、それぞれの使い方を比較することもできます。

> [!NOTE]
> これらのワークショップは [James Montemagno][james] が作成し、[MIT License][source-license] で公開されている [First Steps with GitHub Copilot][source-lab] を基に構成されています。

## ワークショップ

### [GitHub Copilot app を体験する][copilot-app]

空のフォルダーからカラフルな Space Quiz を作り、開発の流れを体験します。作成、改善、テスト、プロジェクトの指示の記録、公開、作業の計画、Issue の実装、プルリクエストのレビューとマージ、定期的な作業の自動化を行い、Canvas 拡張機能も体験します。

### [GitHub Copilot CLI のはじめの一歩][copilot-cli]

ターミナル中心の開発の流れを学びます。Git に変更を記録する前にアプリを作成して差分をレビューし、worktree で複数のセッションを並行して実行し、編集前に計画を立て、コンテキストを管理します。その後、シェルを離れずにプルリクエストを作成、マージし、作業を委任します。

### [Visual Studio Code のはじめの一歩][vscode]

エディター中心の開発の流れを体験します。ワークスペースでアプリを作成し、統合ブラウザーで要素を調整し、コンテキストを確認して、Git に変更を記録する前にテストします。編集前に計画を立て、VS Code を離れずに GitHub ツールで Issue、プルリクエスト、クラウドセッションを扱います。
