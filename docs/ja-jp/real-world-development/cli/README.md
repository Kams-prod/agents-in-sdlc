**[GitHub Copilot CLI][about-copilot-cli]** は、GitHub Copilot をターミナル上のエージェント型コーディングアシスタントとして利用できるツールです。コードベースの調査、コード生成、コマンド実行、外部ツールへの接続をすべてコマンドラインから行えるため、グラフィカルエディターに切り替えずに作業の流れを維持できます。

このワークショップでは、Tailspin Toys の一連のワークフローに取り組みます。

1. GitHub Codespaces でプロジェクトを準備し、Copilot CLI をインストールして、プロジェクトを確認します。
2. 星評価に対象を絞った変更を加え、ブラウザーで確認して、最初のプルリクエスト (PR) を手動でマージします。
3. フィルタリングの Issue から始め、Plan モードで方針を決め、Autopilot モードで実装し、Interactive モードでレビューします。
4. リポジトリの指示を更新し、フィルタリング機能に適用します。
5. 既存の `quality-checks` スキルをカスタマイズし、プロジェクトのチェックを実行します。
6. Playwright Model Context Protocol (MCP) サーバーを追加し、ブラウザーでフィルタリング機能を確認します。
7. 品質保証 (QA) カスタムエージェントを作成し、要件、カバレッジ、検証の証拠をレビューします。
8. フィルタリングの変更全体をレビューし、その PR に Agent Merge を使います。
9. コンテキスト、モデル、共有、cloud agent への任意の委任に使えるスラッシュコマンドを確認します。

ワークショップに集中できるよう、星評価と、指示の更新、スキルの更新、QA プロファイル、テストを含むフィルタリングの 2 つの PR を作成します。フィルタリングと品質ワークフローでは、同じ会話とブランチを使い、各ツールを試しながら作業を積み重ねます。

## 前提条件

このワークショップに参加する前に、次の準備をしてください。

- [ ] **Copilot Student、Pro、Pro+、Business、Enterprise** のいずれかの有効なプランがある GitHub アカウント
- [ ] リポジトリと Codespace を作成する権限
- [ ] ターミナルまたはコマンドライン操作の基本的な知識

> [!TIP]
> 有料プランを利用していませんか？認証済みの学生は [GitHub Education][student-plan] を通じて GitHub Copilot を無料で利用できます。**Copilot Student** プランには、このワークショップで使用するエージェント、MCP、コードレビュー、Copilot CLI の機能が含まれています。

> [!NOTE]
> Copilot Business または Copilot Enterprise を利用する場合は、管理者が組織で Copilot CLI を有効にしていることを確認してください。
